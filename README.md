# 🎭 Mafia LAN — بازی مافیا چندگوشی (اندروید)

**Mafia LAN** یک بازی مافیای چندگوشی برای اندروید است: **گوشیِ میزبان** سرور بازی را داخل خودِ برنامه اجرا می‌کند و
بازیکنانِ دیگر با هات‌اسپات گوشیِ میزبان (یا هر شبکهٔ مشترک) و مرورگر گوشی‌شان به آن می‌پیوندند.
نصب هیچ برنامهٔ اضافه‌ای لازم نیست؛ فقط یک گوشی باید برنامه را نصب کند.

- **نام بستهٔ اندروید:** `ir.mafia.lan`
- **نسخهٔ فعلی:** `1.0.0`
- **وب‌سایت (نسخهٔ ایستا):** <https://sirmahdiw.github.io/mafia-lan/>
- **دانلود نسخه‌ها:** <https://github.com/SirMahdiW/mafia-lan/releases>
- **مخزن کد:** <https://github.com/SirMahdiW/mafia-lan>

## 📥 نصب

### ساده‌ترین روش (بدون Android Studio)
1. به صفحهٔ [Releases](https://github.com/SirMahdiW/mafia-lan/releases) بروید.
2. فایل `app-debug.apk` آخرین نسخه را دانلود کنید.
3. فایل APK را روی گوشی باز کنید و اجازهٔ «نصب از منابع ناشناس» را بدهید.
4. برنامهٔ «مافیا» را باز کنید.

### ساخت از روی کد
1. [Android Studio](https://developer.android.com/studio) (Koala یا جدیدتر) را نصب کنید.
2. این مخزن را باز (Open) کنید و منتظر بمانید Gradle Sync کامل شود.
3. به یک گوشی با USB Debugging وصل شوید و **Run ▶ Run 'app'** را بزنید،
   یا **Build ▶ Build APK(s)** را بزنید.
4. خروجی: `app/build/outputs/apk/debug/app-debug.apk`

> نیازمندی‌ها: JDK 17+، Gradle 8.7، Android SDK با `compileSdk 34` و `build-tools 34.0.0`.

### ساخت با خط فرمان (بدون Android Studio)
```bash
# JDK 17 یا بالاتر
export JAVA_HOME=/path/to/jdk-17
export ANDROID_HOME=$HOME/Android/Sdk
# Gradle 8.7
gradle assembleDebug --no-daemon
# خروجی:
# app/build/outputs/apk/debug/app-debug.apk
```

## 🎮 راهنمای بازی

1. **گوشی میزبان:** هات‌اسپات را روشن کنید و برنامه را باز کنید.
2. در صفحهٔ «بازی چندگوشی» نام خود را بنویسید و **«ورود به بازی»** را بزنید.
3. در سالن انتظار، آدرس/کد QR نمایش‌داده‌شده را به بقیه بدهید.
4. **بقیهٔ گوشی‌ها:** به هات‌اسپات میزبان وصل شوید، آدرس نمایش‌داده‌شده را در مرورگر باز کنید،
   نام بنویسید و وارد شوید.
5. میزبان می‌تواند سناریو و نقش‌ها را تعیین کند و بازی را شروع کند.

> **حالت گرداننده:** اگر فقط یک گوشی دارید، «حالت گرداننده» را انتخاب کنید؛ بازیکنان را وارد کنید و
> گوشی را بین آن‌ها بچرخانید تا هرکس نقش خودش را ببیند.

## 🔧 توسعه و مشارکت

```bash
git clone https://github.com/SirMahdiW/mafia-lan.git
cd mafia-lan
gradle assembleDebug --no-daemon        # ساخت
bash tools/run_cli_test.sh               # اجرای تست خط فرمان
python tools/build_pages.py              # ساخت نسخهٔ ایستای وب‌سایت
```

- شاخهٔ اصلی توسعه: `main` — هر تغییر با **Pull Request** پیشنهاد می‌شود.
- نسخه‌های پایدار با برچسب‌های `vMAJOR.MINOR.PATCH` منتشر می‌شوند؛ هر برچسب یک Release با فایل APK و
  یادداشت تغییرات دارد.
- لطفاً **منطق بازی** (`Engine.kt`)، **رابط کاربری** و **فایل‌های صوتی/تصاویر** را بدون هماهنگی تغییر ندهید.
- پیش از ارسال PR، این‌ها را اجرا کنید:
  ```bash
  gradle assembleDebug --no-daemon
  bash tools/run_cli_test.sh
  ```
